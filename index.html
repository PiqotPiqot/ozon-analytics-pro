Как получить API ключи?

  1. Войдите в кабинет продавца Ozon (seller.ozon.ru)
  2. Перейдите: Настройки → API ключи → Seller API
  3. Нажмите "Сгенерировать ключ"
  4. Скопируйте Client ID и API Key
  5. Вставьте их выше и нажмите "Тестировать"
